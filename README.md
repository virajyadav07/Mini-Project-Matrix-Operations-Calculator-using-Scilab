# Mini-Project-Matrix-Operations-Calculator-using-Scilab
Project Description
This project is a **Matrix Operations Calculator** developed using **Scilab**.  
It performs fundamental matrix operations such as addition, subtraction, multiplication, transpose, determinant, and inverse through a simple menu-driven interface.

Features
1. Matrix Addition
2.Matrix Subtraction
3.Matrix Multiplication
4.Matrix Transpose
5.Matrix Determinant
6.Matrix Inverse
7.Error handling for invalid operations
8.User-friendly interface

 How It Works
1. User inputs two matrices (A and B).
2. The program displays a menu of operations.
3. User selects an operation.
4. The program performs the calculation using Scilab functions.
5. Result is displayed on the console.
   
Technologies Used
 Scilab

  How to Run
1. Install Scilab from the official website.
2. Open Scilab.
3. Load the script file.
4. Follow the on-screen instructions.
